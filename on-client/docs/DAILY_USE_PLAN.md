# 밍밍 보안 Agent — 1일차 점검과 핵심 기능 계획

기준 저장소: https://github.com/mingming-01/mingming-On-client
앱 폴더: on-client/
선택한 화면: 기록 타임라인형
선택한 포장: 기본 포장과 바로가기
이 문서는 현재 소스 계약과 확인 가능한 실행 결과를 구분한 작업 계획입니다. 실제 조회를 실행하지 않은 항목을 성공으로 기록하지 않습니다.

## 현재 상태와 확인 구분

| 기능 | 학생 화면에서 구현된 동작 | 실제 연결 상태 / 제한 |
|---|---|---|
| 보안 기록 타임라인 | 최신 시각순 표시, 종류·업무 앱·접속 상태 필터, 사건 상세·근거·규칙 표시 | 실제 기록은 유효한 SDP 설정과 relay 응답이 있어야 표시됩니다. 화면 열기로 새 위협을 탐지하지 않습니다. |
| 내 계정·기기·세션 | 사용자·기기·세션 값을 상태별 표시하고 오류와 unknown을 구분 | relay가 돌려준 필드만 표시합니다. 현재 기기 보안 준수 상태나 과거 세션은 unknown/미지원일 수 있습니다. |
| 위험 알림 | 조회 실패, 비정상 기기/세션 상태, 저장된 XDR 기록을 한곳에 모음 | 별도 실시간 탐지기가 아닙니다. 조회하지 못한 결과는 안전·위협 없음으로 판정하지 않습니다. |
| OSV 취약점 조회 | 조회 전·중·성공·부분 실패·설정 미완료 상태를 구분 | 운영자가 승인한 공개 패키지와 프로젝트 lock 파일 설정이 필요합니다. 실제 조회를 실행하기 전에는 미확인입니다. |
| 앱 패키징 | 새 패키지 폴더, ZIP, SHA-256 매니페스트, 바탕화면 바로가기 생성 | 로컬 Windows에서 명령을 실행한 뒤 실제 결과를 확인해야 합니다. 인증·설정 파일은 패키징 대상이 아닙니다. |

## 실행과 실제 연결

일반 실행은 서버 및 화면을 확인하는 절차이며, 실제 SDP 연결 성공을 보장하지 않습니다.

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\tools\start-alekov.ps1 -Port 5191
```

실제 연결 설정을 운영자로부터 발급받은 경우에만 다음처럼 경로를 지정합니다.

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\tools\start-alekov.ps1 -Port 5191 -SdpHostConfig "C:\실제로_발급받은_경로\sdp-host.json"
```

위 경로는 설명용 자리표시자입니다. 설정 파일을 만들거나 그 내용을 복사하지 말고, 발급받은 실제 경로만 사용합니다. 비밀값과 개인 자격 자료는 Git·앱 패키지·화면 캡처에 넣지 않습니다.

## 다듬을 핵심 기능 순서

1. **보안 기록 타임라인** — 실제 조회/예제/연결 실패를 명확히 구분하고 최신순·종류·앱·접속 상태 필터와 상세 근거를 검증합니다.
2. **내 계정·기기·세션 상태** — 조회된 값, unknown, 요청 실패를 분리해 연결 오류를 정상 상태로 오해하지 않게 합니다.
3. **위험 알림·취약점 현황** — 저장된 XDR 경보, 기기·세션 주의 상태, OSV 조회 결과의 출처와 미확인 범위를 함께 표시합니다.

## 재현 확인 순서

1. npm run check를 실행합니다. 이 명령은 문법 검사이지 API 통합 테스트가 아닙니다.
2. 실행 도구로 앱을 켜고 브라우저에서 http://127.0.0.1:5191/을 엽니다.
3. 상단 모드와 각 자료 상태를 확인합니다. 연결 설정이 없으면 ENGINE_NOT_CONNECTED를 실패 상태로 기록합니다.
4. 발급받은 SDP 설정이 있을 때만 설정 경로를 지정해 다시 실행하고, 본인 기록·기기·세션 응답을 각각 확인합니다. 한 기능의 성공을 다른 기능의 성공 근거로 쓰지 않습니다.
5. npm run package-app을 실행해 출력 경로, ZIP, 매니페스트, 바로가기가 만들어지는지 확인합니다.
6. 바로가기는 기본 실행 경로를 사용합니다. 실제 연결이 필요한 경우 운영자 발급 설정을 지정한 명령으로 실행합니다.

## 현재 미검증

이 문서를 작성한 것만으로 실제 사용자의 SDP 연결, 운영 relay의 이벤트 데이터, 실제 OSV 응답, 바탕화면 바로가기 실행, 공식 ALEPH 제출·심판을 통과했다고 주장하지 않습니다. 각각 실제 환경에서 실행한 결과로 따로 갱신해야 합니다.
