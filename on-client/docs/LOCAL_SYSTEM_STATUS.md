# 내 PC 상태: 실측과 추이 비교

## 제공 기능과 학생 구현 구분

- 기존 제공 기능: 계정·기기·세션, 보안 기록, 보안 상태와 위험 알림, 연결 점검.
- 기존 제공 기능에는 현재 PC의 CPU 사용률·메모리 사용량·디스크 남은 공간을 실측하는 API가 없어 별도 읽기 전용 경로 `GET /api/local-system`와 화면을 추가했습니다.
- 학생 구현: 화면의 「지금 측정」을 직접 눌렀을 때만 값을 조회하고, 같은 브라우저 화면을 열어 둔 동안 최근 10회 실측을 타임라인으로 비교합니다.

## 측정값과 출처

- CPU 사용률: `node:os`의 `cpus()` 누적 시간 값을 약 400ms 간격으로 두 번 읽어 차이를 계산합니다. 단위는 `%`입니다. 순간 센서 수치가 아니라 짧은 간격의 운영체제 시간 기반 추정치입니다.
- 메모리: `node:os`의 `totalmem()`과 `freemem()`을 이용합니다. 사용량·전체·사용 가능 용량은 GiB, 사용률은 `%`입니다.
- 디스크: `node:fs/promises`의 `statfs()`로 시스템 드라이브의 전체 블록과 일반 사용자에게 사용 가능한 블록을 읽습니다. 남은/전체 용량은 GiB, 사용률은 `%`입니다. 이 값은 관리자 전용 예약 공간이 아니라 일반 사용자에게 사용 가능한 공간을 기준으로 표시합니다.
- 각 지표는 개별 측정 시각, 단위, 출처를 표시합니다. 서버 응답의 지표 하나가 실패해도 나머지 지표의 성공 여부는 별도로 보여 줍니다.

## 실패와 개인정보 처리

- 측정에 실패한 값은 0이나 예시 값으로 대체하지 않고 「확인 불가」와 실패 이유를 표시합니다.
- 이 기능은 운영체제 정보를 읽기만 하며 관리자 권한 상승, 설정 변경, 프로세스 종료, 보안 판정 변경을 수행하지 않습니다.
- 사용자가 버튼을 눌렀을 때만 측정합니다. 자동 주기 측정, 디스크 저장, 계정·외부 서버 전송은 없습니다.
- 최근 10회 추이는 브라우저 화면이 열려 있는 동안 메모리에만 유지됩니다. 새로 고침/페이지 재접속 시 사라집니다.
- 디스크 측정은 시스템 드라이브를 대상으로 합니다. 다른 드라이브의 남은 공간을 뜻하지 않습니다.

## 재현 및 확인

프로젝트 루트의 Git Bash에서:

```bash
cd on-client
npm run check
npm start
```

화면에서 「지금 측정」을 한 번 눌러 세 지표의 단위·측정 시각·출처를 확인합니다. 다시 누르면 이전 실측과의 차이가 나타납니다. 드라이브 조회가 지원되지 않거나 접근할 수 없는 환경에서는 해당 디스크 항목만 「확인 불가」와 이유를 표시해야 합니다.

포장 명령은 작업 트리가 깨끗한 커밋 상태에서 실행해야 합니다. 변경을 검토하고 커밋한 뒤:

```bash
npm run package-app
```

기존 패키지나 제출물을 덮어쓰지 않고 새 버전 이름의 패키지를 생성합니다.
