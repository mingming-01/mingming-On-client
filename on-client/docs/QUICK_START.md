# 밍밍 빠른 실행 안내

이 문서는 화면 시연과 패키지 상태를 확인할 때 사용합니다. 현재 패키지 생성 도구는 승인된 운영 호스트 바로가기를 만들지 않습니다. 운영 실행은 담당 운영자가 승인된 런타임과 바로가기 절차를 안내하기 전까지 준비 필요 상태입니다.

## 1. 준비

1. 받은 ZIP을 파일 탐색기에서 별도 폴더에 압축 해제합니다. ZIP 안에서 바로 실행하지 않습니다.
2. Windows와 Node.js 22~24가 필요합니다. 권장 기준은 Node.js 24.19.0입니다.
3. PowerShell 또는 Git Bash에서 `node -v`로 실제 설치 버전을 확인합니다. 이 안내만으로 현재 PC의 실제 버전을 확인한 것으로 간주하지 않습니다.
4. 이 패키지에는 외부 npm 의존성이 선언되어 있지 않아 기본 화면 시연을 위해 `npm install`을 실행할 필요가 없습니다.

## 2. 화면 시연 (예제 모드 전용)

앱 폴더에서 PowerShell 또는 Git Bash를 열고 다음 명령을 실행합니다.

```bash
npm run demo
```

브라우저에서 `http://127.0.0.1:5189/`을 열어 다음 순서로 확인합니다.

1. **계정·기기·세션 상태** — 항목별 값과 연결 모드를 확인합니다.
2. **업무 앱 접근 판정** — 판정·이유·시각을 확인합니다.
3. **보안 기록 타임라인** — 기록 종류, 업무 앱, 접속 상태 필터를 각각 바꾸고 기록 상세의 근거·규칙·상태를 확인합니다.

이 명령은 화면 시연을 위한 **demo 예제 모드**입니다. 화면이 열리거나 예제 기록이 보였다는 사실은 실제 SDP 서버·계정·XDR 시스템에 연결됐다는 뜻이 아닙니다. 타임라인에 예제 기록이 보이면 예제 자료임을 시연 중에 말합니다. 서버를 종료하려면 실행 중인 터미널에서 `Ctrl+C`를 누릅니다.

## 3. 실제 값과 예제·미연결·확인 불가 구분

- `demo`: 화면 설명용 예제 데이터입니다. 실제 PC나 운영 서비스의 결과가 아닙니다.
- 실제 PC 실측: 화면에서 내 PC 상태를 직접 조회하고 측정 시각·단위·출처가 표시된 경우에만 실제 측정값으로 기록합니다. 이번 값이 없거나 요청에 실패하면 `확인 불가`로 남깁니다.
- `disconnected`: 실제 엔진/SDP 연결 경로가 준비되지 않은 상태입니다. 정상이나 안전하다는 의미가 아닙니다.
- `connected`: 연결 설정이 있다는 표시만으로는 충분하지 않습니다. 이번 API 응답이 성공하고 데이터 계약 검증을 통과해야 조회 결과를 확인된 것으로 취급합니다.
- `unknown`, 오류, 응답 형식 불일치, 미조회: 실제 조회 성공으로 바꾸거나 빈 성공 결과로 대신하지 않습니다.

Windows System·Application 로그의 경고·오류 건수는 이벤트 기록 수이며, 그 자체로 공격이나 침입이 탐지되었다는 뜻은 아닙니다.

## 4. 운영 실행 준비

현재 저장소에서는 승인된 운영 호스트 런타임의 설치 명령, 등록된 호스트 바로가기 규격 및 운영 앱 승인 키 검증 절차를 확인하지 못했습니다. 따라서 패키지에는 승인된 바탕화면 바로가기가 없으며, 아래 안내는 이를 임의의 실행 스크립트나 옵션으로 대체하지 않습니다.

- 런타임 상태가 `PROVIDED_RUNTIME_NOT_INSTALLED`이면 운영자 준비가 필요합니다.
- 운영 앱 승인 키가 없거나 검증되지 않은 경우에도 운영자 준비가 필요합니다.
- 담당 운영자에게 승인된 런타임, 바로가기 등록 도구, 실행 명령 및 승인 확인 절차를 문의합니다.
- `--app-only-v1`로 승인 절차를 우회하지 않습니다.
- SDP 설정 파일, 인증서, 개인키, 토큰, 승인 키 값은 프로젝트·ZIP·Git·채팅·캡처에 넣지 않습니다.

승인된 실제 SDP 연결이 필요한 경우 담당 운영자로부터 발급받은 설정 파일과 승인 실행 절차를 사용합니다. 설정 경로는 설명용 값으로 만들어 실행하지 않습니다.

## 5. 자주 만나는 문제

| 메시지 또는 상황 | 다음에 할 일 |
|---|---|
| `Node.js 가 없습니다` | Node.js 24.19.0 설치 여부와 새 터미널의 PATH를 확인합니다. |
| `지금 Node.js 는 vXX 입니다` | 시작 도구는 22~24를 허용하고 수업 기준은 24.19.0입니다. |
| 포트 5189를 사용 중 | 기존 프로그램을 종료하지 말고 포트 충돌을 기록합니다. 운영 실행 포트를 임의로 변경하지 말고 담당 안내를 따릅니다. |
| 앱이 정해진 시간 안에 응답하지 않음 | 실행 창의 오류를 기록하되 사용자 이름·개인 경로·내부 주소·비밀값은 가립니다. |
| SDP 연결을 확인할 수 없음 | 연결 성공으로 단정하지 않습니다. 설정과 권한을 임의 변경하지 말고 담당 운영자에게 확인합니다. |
| 기록이나 상태가 `unknown` / `확인 불가` | 정상 상태로 보정하지 않고 해당 이유와 조회 시각을 기록합니다. |

도움이 필요하면 오류가 발생한 단계와 비밀값을 제거한 오류 메시지를 공유합니다. SDP 설정 내용·인증서·개인키·JWT·운영 앱 승인 키는 공유하지 않습니다.
