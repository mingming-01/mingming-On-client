# 밍밍 빠른 실행 안내

이 문서는 ZIP 패키지와 바탕화면 바로가기를 사용하는 사람을 위한 안내입니다. 처음 실행할 때는 아래 순서대로 진행하세요.

## 1. 압축 해제와 준비

1. 받은 `.zip` 파일을 파일 탐색기에서 원하는 폴더에 압축 해제합니다. ZIP 파일 안에서 바로 실행하지 마세요.
2. Windows에 Node.js 22~24가 설치되어 있어야 합니다. 수업 기준 버전은 `24.19.0`입니다.
3. 설치 여부는 PowerShell에서 `node -v`로 확인합니다. 명령을 찾을 수 없으면 Node.js 24.19.0을 설치하고 PowerShell을 새로 여세요.

## 2. 기본 실행

1. 압축 해제 후 만들어진 밍밍 바탕화면 바로가기를 실행합니다.
2. 브라우저가 열리면 보호 현황 화면을 확인합니다. 기본 주소는 `http://127.0.0.1:5189/`입니다.
3. 내 PC 상태와 네트워크·방화벽 조회는 이 PC에서 읽은 실제 결과를 표시합니다. 항목을 새로 읽으려면 화면의 조회 버튼을 누릅니다.

## 3. '연결 없음'이 표시될 때

바탕화면 바로가기는 개인 인증 정보가 들어 있지 않은 기본 실행 방식입니다. 따라서 SDP 설정 경로를 따로 지정하지 않았다면 로그인 정보, 업무 앱, 보안 기록, 기기, 세션에 **연결 없음**이 표시될 수 있습니다. 이는 화면이 연결 성공을 확인하지 못했다는 뜻이며, 실제 서버에 연결되었다고 판단해서는 안 됩니다.

실제 SDP 연결이 필요한 경우 담당 운영자에게 본인용 SDP 설정 파일을 발급받아야 합니다. 이 파일에는 개인 인증 경로가 포함될 수 있으므로 앱 폴더·Git·ZIP·채팅에 복사하지 마세요.

설정 파일을 발급받았다면, **압축 해제한 패키지 폴더**에서 PowerShell을 열고 다음 명령의 경로를 실제 파일 위치로 바꾸어 실행합니다.

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\tools\launch-mingming.ps1 -SdpHostConfig "C:\실제로_발급받은_경로\sdp-host.json"
```

위 경로는 설명용 예시로 그대로 실행하면 안 됩니다. 운영자가 발급한 실제 절대 경로로 바꿔야 합니다. 이 명령이 실제 SDP 원천에서 본인 identity 응답을 확인하기 전까지는 연결 성공으로 보지 않습니다. 설정을 발급받지 못했다면 임의로 파일이나 값을 만들지 말고 담당 운영자에게 요청하세요.

## 4. 자주 만나는 문제

| 메시지 또는 상황 | 다음에 할 일 |
|---|---|
| `Node.js 가 없습니다` | Node.js 24.19.0을 설치하고 PowerShell을 새로 여세요. |
| `지금 Node.js 는 vXX 입니다` | Node.js 22~24를 사용하세요. 수업 기준은 24.19.0입니다. |
| 포트 5189를 사용 중이라고 표시 | 기존 프로그램을 종료하지 마세요. 패키지 폴더에서 `launch-mingming.ps1 -Port 5190`으로 실행하고 브라우저 주소도 5190인지 확인하세요. |
| 앱이 정해진 시간 안에 응답하지 않음 | 서버 PowerShell 창의 오류 전문을 확인하세요. 반복되면 오류 문구를 담당자에게 전달하세요. |
| SDP 연결을 확인할 수 없음 | 설정 경로가 실제 파일을 가리키는지 확인하세요. 연결 설정이나 권한을 임의로 바꾸지 말고 담당 운영자에게 문의하세요. |

## 5. 종료와 데이터 구분

- 서버를 종료하려면 서버가 실행 중인 PowerShell 창에서 `Ctrl+C`를 누릅니다.
- `예제(demo)`는 설명용 값이며 실제 PC나 서버에서 읽은 결과가 아닙니다.
- 실제 조회값은 성공한 조회 응답에 한해 표시됩니다. 조회 실패나 확인 불가는 예시값 또는 빈 성공 결과로 대체하지 않습니다.
- Windows System·Application 로그의 경고·오류 건수는 이벤트 기록 수이며, 그 자체로 공격이나 침입이 탐지되었다는 뜻은 아닙니다.

도움이 필요하면 오류 문구와 발생 단계를 공유하되, SDP 설정 파일 내용·인증서·개인키·JWT는 공유하지 마세요.
